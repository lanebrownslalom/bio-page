# My Links - Project Brief
A personal Link-in-bio page. One page, clear design, mobile-first. I want to send people here from my social profiles.

## Tech
- Pure HTML, CSS and Javascript - no frameworks, no build tool
- Songle, index.html file (CSS and JS can be separate files)
- Deploys to Vercel as a static site

## Design
- Centered card layout, max-width 480px
- My name as a heading, short bio underneath which reads "Writer and strategist wrangling life's adventures to tell stories and build connections."  
- Profile photo placeholder (circle, 120px)
- Light mode by default with a light/dark toggle
- smooth hover animations over the link buttons
- Google Font: Google Sans
- Use warm oranges and pinks in light mode
